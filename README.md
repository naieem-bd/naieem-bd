## About me

I'm a front-end engineer with **9+ years of experience**. Right now I'm the sole front-end engineer for three production SaaS applications at **SwitchFX Technologies** (Atlanta, USA), where I own the front end from architecture and UI through API integration and production delivery.

The kind of work I'm usually trusted with:

- **Authentication** — OAuth 2.0 / OIDC, PKCE, JWT/JWKS verification, httpOnly cookie sessions, silent token refresh
- **Backend-for-Frontend** — 30+ typed Next.js route handlers with Zod validation and a single, consistent error contract
- **SaaS foundations** — multi-tenant organizations, RBAC, team invitations, API-key management, Stripe billing with plan changes, proration and customer portal
- **Quality & delivery** — Jest, React Testing Library, Playwright, CI/CD with GitHub Actions and Docker

## What I'm working on

- 📰 **Newsora** — developer dashboard, live news search, usage tracking, interactive API docs and billing, built with Next.js 16 (App Router, RSC), React 19, Tailwind CSS v4 and shadcn/ui
- 🔐 **SwitchFX Auth & MyAccount** — centralized SSO, email verification, password and account management
- 🌱 **Learning** — building AI features into products: LLM APIs, RAG, tool calling and agents, with Python and FastAPI
